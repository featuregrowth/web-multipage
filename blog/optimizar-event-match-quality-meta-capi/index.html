Meta CAPI · EMQ · Atribución

Guía de Optimización del Event Match Quality en la API de Conversiones

Por Matías · Cofundador · Data & Tecnología · Conocer al equipo

Parámetros de coincidencia clave (External ID, Email hash, fbp, fbc)

El Event Match Quality (EMQ) es la métrica de Meta que califica de 1 a 10 la eficacia del envío de datos de conversión. Optimizar el EMQ exige enviar parámetros clave como Email y Teléfono hasheados en SHA256, junto con External ID, cookies fbp/fbc y datos de ubicación del cliente desde el servidor.

Script en Python para hasheo SHA256 antes del envío server-side

A continuación se muestra la función estándar en Python para normalizar y hashear los datos del usuario antes de transmitirlos a Meta CAPI:

import hashlib

def hash_user_data(data_string):
    """
    Normaliza y genera hash SHA256 para parametros de Meta CAPI (Email, Phone, City).
    """
    if not data_string:
        return None
    normalized_string = data_string.strip().lower()
    return hashlib.sha256(normalized_string.encode('utf-8')).hexdigest()

# Ejemplo de uso para parametro Email:
raw_email = " Cliente@Empresa.com "
hashed_email = hash_user_data(raw_email)
# Resultado SHA256 listo para payload JSON de Meta CAPI
