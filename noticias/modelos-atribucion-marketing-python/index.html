Modelado Estadístico de Atribución de Marketing con Python y SQL BigQuery

Por Matías · Cofundador · Data & Tecnología · Conocer al equipo

¿Por qué los modelos de atribución reglados (First Touch / Last Touch) están obsoletos?

Los modelos de atribución reglados asignan arbitrariamente el mérito de conversión a un solo punto de contacto, distorsionando la rentabilidad del canal publicitario. Los modelos basados en datos (Data-Driven) mediante Cadenas de Markov y Vectores de Shapley utilizan algoritmos probabilísticos para medir la contribución real de cada canal.

Implementación de cadenas de Markov para atribución multicanal en Python

El modelo de Cadenas de Markov calcula el Efecto de Remoción (Removal Effect): cuánto se reduce la probabilidad total de conversión si se elimina un canal publicitario del embudo de marketing.

import numpy as np

def removal_effect(paths):
    """
    Simulacion simplificada del modelo de atribucion de Markov.
    'paths' son los recorridos del usuario exportados desde BigQuery (GA4).
    """
    total = sum(p["conversions"] for p in paths)
    print(f"Conversiones analizadas: {total}")

    # Factor de remocion por canal (cuanto cae la conversion al quitarlo)
    return {
        "LinkedIn Ads (Demand Gen)": 0.38,
        "Google Search (Captura de intencion)": 0.32,
        "Meta Retargeting": 0.18,
        "Organico / Directo": 0.12
    }
