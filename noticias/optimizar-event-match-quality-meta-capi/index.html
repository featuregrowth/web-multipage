Meta CAPI · EMQ · Atribución

Guía de Optimización del Event Match Quality (EMQ) en la API de Conversiones

Por Matías · Cofundador · Data & Tecnología · Conocer al equipo

¿Qué es el Event Match Quality (EMQ) de Meta Ads?

El Event Match Quality (EMQ) es una puntuación de 1 a 10 con la que Meta evalúa la capacidad de asociar los eventos de conversión enviados con usuarios reales de la plataforma. Subir el EMQ requiere enviar datos del cliente hasheados en SHA256 junto con las cookies fbp y fbc y el External ID desde el servidor.

Script de normalización y hasheo SHA256 en Python

Este es el código estandarizado para procesar de forma segura los parámetros del usuario antes de transmitirlos en el JSON payload de la API de Conversiones:

import hashlib

def normalize_and_hash(parameter_value):
    """
    Normaliza y genera hash SHA256 conforme a los requerimientos de Meta CAPI.
    """
    if not parameter_value:
        return None
    # Paso 1: Eliminar espacios y convertir a minusculas
    clean_value = parameter_value.strip().lower()
    # Paso 2: Generar digest SHA256
    return hashlib.sha256(clean_value.encode('utf-8')).hexdigest()

# Preparacion del payload para Meta CAPI desde el servidor:
user_data_payload = {
    "em": normalize_and_hash(" Juan.Perez@Empresa.com "),
    "ph": normalize_and_hash(" +54 9 11 1234 5678 "),
    "fn": normalize_and_hash("Juan"),
    "ln": normalize_and_hash("Perez"),
    "external_id": normalize_and_hash("USR-89421")
}

print(user_data_payload)
# Salida: {'em': 'a1b2c3d4...', 'ph': '...', 'fn': '...', 'ln': '...', 'external_id': '...'}

Checklist para alcanzar un EMQ superior a 8.5/10

  • Transmitir de forma obligatoria las cookies de navegador _fbp y _fbc extraídas del encabezado HTTP.
  • Inyectar el parámetro external_id del cliente sincronizado con el ID único del CRM o la base de datos.
  • Asegurar la coincidencia exacta de los nombres de eventos (ej. Purchase, Lead) entre el Pixel y CAPI para permitir la deduplicación con event_id.
